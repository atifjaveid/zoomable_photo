# zoomable_photo example

A photo grid that opens a full-screen gallery. Photos come from [Lorem Picsum](https://picsum.photos), which serves free photos from [Unsplash](https://unsplash.com).

- Tap a photo to open it, with a Hero animation.
- Pinch, double-tap or scroll the mouse wheel to zoom; drag to move a zoomed photo.
- Swipe, use the arrows at the bottom, or press the arrow keys to move between photos.
- Tap the infinity button to make the gallery loop.
- Tap a photo once to hide or show the controls.

```sh
cd example
flutter run
```

Everything is in [lib/main.dart](lib/main.dart).
